## สิ่งที่ควรทำต่อ (เรียงตามความคุ้มค่า)

1. **กด ▶ Run Simulator ดูจอด้วยตา** — งาน ⚠️ ค้างอยู่หลายอย่าง ใช้เวลาไม่นานแต่ปลดล็อกได้เยอะ
   เน้นดู overlay PASS/NG (ขนาด/ตำแหน่งข้อความ) แล้วขยับค่า `VG_*` บนหัว `MainScreenView.cpp`
2. **เก็บรูปหลักฐาน** — ดู `docs/thesis/evidence/INDEX.md` ข้อ 1–3 (เก็บย้อนหลังไม่ได้)
3. **เติม `machine_spec.md`** — เป็นต้นน้ำที่งานส่วนอื่นอ้างอิง
4. ตัดสินใจเรื่องชุดชื่อ state (ดู `fsm_spec.md` ข้อ 4)
5. `cargo build` ใหม่ก่อนใช้ Rust bridge
6. ต่อ `machine_params` เข้ากับ FSM จริง (`motor_speed` → `speed_mul`, `temperature` → ช่วงที่ยอมรับใน `CHECK_TEMP`)

> **แผนกับของจริงไม่ตรงกันหลายจุด** — ควรให้ `documentation` ทวนกับสถานะจริงแล้วอัปเดต % ในตารางนี้
