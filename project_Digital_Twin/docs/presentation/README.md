# presentation — สไลด์นำเสนอ


## กติกา

**เก็บ outline `.md` คู่กับ `.pptx` เสมอ** — แก้ outline ง่ายกว่าแก้ pptx
และ `thesis-archivist` เอา outline ไปต่อเป็นเนื้อรูปเล่มได้เลย

ชื่อไฟล์: `YYYY-MM-DD-<ประเภท>.pptx` เช่น `2026-08-10-weekly.pptx`

## ประเภทสไลด์

| ประเภท | จำนวนสไลด์ | โครง |
|---|---|---|
| `weekly` | 5–8 | ทำอะไรเสร็จ → ติดอะไร → สัปดาห์หน้าทำอะไร → ต้องการการตัดสินใจอะไร |
| `defense` | 15–25 | ที่มา → วัตถุประสงค์ → ขอบเขต → ทฤษฎี → ออกแบบเครื่อง → ระบบควบคุม → Digital Twin → ผลทดสอบ → สรุป |
| `demo` | ตามเนื้อหา | เน้นภาพ/วิดีโอ ตัวอักษรน้อย |

## กฎที่ต้องรักษา

- หัวข้อสไลด์ต้องเป็น**ข้อสรุป** ไม่ใช่หัวข้อลอย ๆ
  ✅ "FSM หยุดรอ operator ที่สเต็ป VISION ได้จริง" ❌ "การทดสอบ"
- ตัวเลขทุกตัวต้องอ้างไฟล์+วันที่ที่ท้ายสไลด์
- ใช้สถานะให้ตรง: ✅ ทดสอบผ่านแล้ว / ⚠️ ทำเสร็จแต่ยังไม่ได้ตรวจด้วยตา / 🔄 กำลังทำ / ⏳ ยังไม่เริ่ม
- ใส่ speaker notes ทุกสไลด์
- diagram ใช้ของที่มีใน repo (mermaid ใน `fsm_spec.md`) อย่าวาดใหม่ให้ต่างจากของจริง
