# tools/ — สคริปต์วินิจฉัยฮาร์ดแวร์ (Hardware Diagnostics)

โฟลเดอร์นี้เก็บสคริปต์ที่ใช้ **รันด้วยมือ (run by hand)** เพื่อทดสอบ/วินิจฉัยฮาร์ดแวร์จริงโดยตรง
**ไม่ใช่** ส่วนหนึ่งของชุดทดสอบอัตโนมัติ (automated test suite) — ชุดทดสอบอัตโนมัติของโปรเจกต์อยู่ที่
`python_backend/tests/` แยกต่างหาก

## `modbus_io_test.py`

เดิมชื่อ `test.py` (ย้ายมาจาก root ของ repo และเปลี่ยนชื่อเมื่อ 2026-08-04 เพราะชื่อเดิมทำให้เข้าใจผิดว่าเป็น
unit test) สคริปต์นี้เปิดการเชื่อมต่อ Modbus/TCP แบบดิบ (raw socket ไม่ใช้ไลบรารี pymodbus) ไปยังตัวควบคุม H7
โดยตรง เพื่อ:

- ส่ง heartbeat คำสั่ง `*IDN?` เพื่อตรวจสอบว่าตัวควบคุมยังตอบสนองอยู่
- อ่านค่า input bit-bank และเขียนค่า output bit-bank
- กะพริบ (blink) เอาต์พุตเพื่อทดสอบการทำงานจริง
- แสดงแดชบอร์ดสถานะแบบสด (live console dashboard) ในเทอร์มินัล

**ต้องใช้ฮาร์ดแวร์จริง** — สคริปต์นี้เชื่อมต่อไปยัง `192.168.0.100:502` (ค่า default ที่กำหนดในไฟล์ ผ่านตัวแปร
`H7_IP` / `H7_PORT`) ห้ามรันในระบบ CI หรือระหว่างทดสอบอัตโนมัติ เพราะจะพยายามเชื่อมต่อเครือข่ายไปยังอุปกรณ์จริง
